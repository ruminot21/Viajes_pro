SISTEMA VIAJAPRO

1. Abre index.html para ver la página pública.
2. Abre admin.html para entrar al panel de administración.
3. Usuario: admin
4. Contraseña: 1234

Funciones incluidas:
- Crear, editar y eliminar viajes.
- Configurar destino, origen, fecha, hora, precio por persona y cantidad de asientos.
- Selección visual de asientos.
- Reservas con código único.
- Consulta de reservas.
- Panel con estadísticas.
- Ajustes de empresa y moneda.
- Diseño adaptable a teléfonos, tablets y computadores.
- Datos guardados con localStorage.

Nota:
Esta versión funciona completamente en el navegador y no necesita servidor.
Para uso real con varios usuarios al mismo tiempo se recomienda conectar una base de datos y un sistema de autenticación seguro.
